# PCBA 与 AI 设计流程调研

用户希望进一步紧凑化，并要求调查嘉立创及 AI 操作案例。调研阶段通过用户的 Edge 浏览器查看国内嘉立创 PCB、SMT 工艺和帮助页面，另查阅官方文档与社区源码；当时尚未安装 EDA/AI 桥接工具，未上传工程或下单。

后续安装进展：用户授权后，官方 Skill 已通过 `upstreams/` 子模块与仓库内符号链接接入；专业版 3.2.203 与 Run API Gateway 1.0.6 已连通。独立分压测试电路完成保存重开、工程包导出和网表核对；名片电路、PCB 与制造文件尚未完成。具体版本、启动方式和接口兼容性记录见 [软件安装记录](software.md)。下文案例表保留调研时的证据范围。

## 当前建议

成品路线优先评估 **nRF52840 薄模块 + 定制 PCB + 工厂贴片**；现成开发板保留作桌面功能验证。把供电、USB、按键和屏幕驱动电路统一排布，有机会减少多块成品板、排针和飞线占用。PCBA 负责装焊，最终厚度仍取决于器件、布局、外壳与公差；≤5 mm 尚未验证。

嘉立创适合作为首选询价对象：国内 PCB、元件采购、SMT 与 EDA 配套齐全，另有外壳打印服务。此判断针对本项目的少量样板与 AI 辅助流程，不代表已经比较实际价格、良率或交期。可用同一套制造文件向 [华秋 PCBA](https://www.hqpcb.com/hqsmt.html) 获取对照报价；目前没有任一供应商的本项目报价。

## 工厂与我们的分工

| 工作 | 范围与本项目待确认项 |
| --- | --- |
| PCB 制造、采购、装焊 | [嘉立创 SMT](https://www.jlc-smt.com/) 明确提供 PCB、元件、钢网、SMT 配套；具体模块、FPC 座及 USB-C 的供货和工艺需按 BOM 核对 |
| 外壳 | [嘉立创 3D 打印](https://www.jlc.com/portal/server_guide_60601.html) 可单独提交模型；模型、材料、薄壁与透明后处理需要独立评审 |
| 烧录与功能测试 | 需明确固件、接口、测试步骤和验收标准，另行确认服务及费用；不能把焊接检查当成 NFC/屏幕/充电已经通过 |
| 屏幕、电池、外壳总装 | 暂按我们收到板后完成；如希望外包，需把装配图和工序提交确认，普通 SMT 下单不等于已包含整机装配 |
| 电路、固件、机械设计 | 由项目完成并评审；制造商的可制造性检查不能替代功能验证 |

国内 [SMT 工艺能力表](https://www.jlc-smt.com/vtechnology) 于 2026-09-20 浏览核对：

- 经济型列出单面贴片及插件、板厚 **0.8–1.6 mm**、尺寸 **10×10 至 470×570 mm**。
- 标准型列出单/双面贴片及插件，尺寸 **70×70 至 460×510 mm**，需要工艺边和 MARK 点。86×54 mm 名片若用此服务，需要确认拼板或工艺边方案。
- 标准型列出 FCT 等检测能力；具体订单包含哪些检测、是否需要治具，要另行约定。

因此先以 **0.8 mm PCB、尽量单面装焊** 做可行性比较，尚不冻结层数或厚度；0.6 mm 薄板不能直接套用经济型条件。页面对标准型部分参数写“无限制”，不能据此假定任意薄板和器件均可加工。

费用等 Gerber、BOM 和贴装坐标文件形成后再实报。工程费起价不包含所有元件、PCB、装焊及附加服务；此前接近千元的估算不作为预算依据。可先比较贴装 3 块板、只配 1 套屏幕/电池/壳体的组合，裸板与贴装最小数量分别核对；同版多做不能消除共同设计错误。

## 找到的 AI 工具与案例

以下是研究资料，不是已经在本机验证的能力，也未执行第三方安装脚本。

| 来源 | 能证明什么 | 证据边界 |
| --- | --- | --- |
| [EasyEDA 官方辅助项目目录](https://prodocs.lceda.cn/cn/api/guide/ancillary-projects.html) 与 [easyeda-api-skill](https://github.com/easyeda/easyeda-api-skill) | 官方提供 API Skill、桥接与 EDA 扩展，让 AI 通过接口读写设计 | 本机 macOS、当前客户端和保存/导出流程尚未验证 |
| [daishuge/pcb-skill 案例](https://github.com/daishuge/pcb-skill/blob/main/docs/case-study.md) | 记录 AI 辅助电路设计、检查及制造文件准备；复核发现过错网、连接器方向和空间冲突 | 作者明确注明尚未制板、组装和通电；案例采用手焊，不能作为 PCBA 实物成功证据 |
| [DaCapo7/easyeda-agent-toolkit](https://github.com/DaCapo7/easyeda-agent-toolkit) | 提供网表、原理图、PCB 同步、检查及导出脚本 | 部分界面自动化依赖 Windows；作者明确仍需人工处理复杂布局布线，不能直接视作本机可用 |

据此建议先试 **EasyEDA Pro 官方 API 路线**，FreeCAD 继续负责结构；KiCad 保留为备选，不同时维护两份电路源文件。选择嘉立创制造并不要求使用其 EDA。浏览器适合选料、查看制造反馈与报价；电路编辑优先验证可复现的 EDA 接口。第三方案例中自动跳过确认的脚本不纳入本项目流程。

## 下一步与通过条件

1. 小型原理图工具验证已通过：在独立本地工程中放置两颗 10 kΩ 电阻、连线、保存、从磁盘重开，并导出工程和网表核对实际连接。继续用 EasyEDA Pro 推进；后续还需验证 PCB 布局、ERC/DRC、Gerber、BOM、贴装坐标及 STEP 导出。
2. 建立功能框图和候选 BOM，先核对 nRF52840 模块 NFC 引脚、USB/首烧接口、屏幕驱动及 FPC、电池完整包体和充电电流；同时查库存、封装和高度。
3. 联合排布 PCB 与 FreeCAD 模型，纳入 NFC 线圈、电池、插座、按键、固定结构和公差；更新当前简化包络模型。确认制造服务能处理选定板厚和装焊面。
4. 原理图检查、网表复核、PCB 规则检查和机械检查通过后，导出 Gerber、BOM、贴装坐标及 STEP，取得正式报价和制造反馈。
5. 首板完成 USB、NFC、屏幕、按键、充电和装壳验证后再定后续数量。设计检查能降低返工概率，实物验证仍是独立步骤。
