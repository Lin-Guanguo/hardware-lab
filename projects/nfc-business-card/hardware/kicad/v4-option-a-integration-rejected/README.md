# NFC V4 方案 A 整板合并失败对照

## 当前确定方案

此工程保留一次允许拆改非 NFC 铜线的整板合并结果，**未采纳，禁止制造**。完整原理图／项目库与 A 相同，76 封装、66 件 BOM及采样功能均保留。入口：[项目](NFC-Card-V4.kicad_pro)、[PCB](NFC-Card-V4.kicad_pcb)。

612 段／57 孔，原生 DRC 55、26 未连接、parity 0。五充电控制和六屏幕信号虽同版接通，但 C3/C4/U3 等局部地失去到 U2 EP 的连接；USB、SWD 等关键路径仍不完整。

具体对象、返回隔离、未连接清单、删采样对照及推荐下一步见 [方案 A 报告](../../v4-option-a-review.md)。可继续研究的局部验证入口另见 [A 工程](../v4-option-a/README.md)；保留失败铜用于诊断，不锁定其布线或器件位置。
