# 面包板入门与屏幕、按钮准备

## 当前目标

2026-09-19：摄像头和原生 USB 拍照已验证。下一步先学会面包板连接，再做“按一次按钮，屏幕计数加一”，最后接入拍照功能。

用户现已确认屏幕八针标注为 `GND VCC SCL SDA RST DC CS BL`，并报告使用母对母杜邦线直连，见[屏幕接线表](../hardware/display-wiring.md)。用户已目视确认基本显示；按键近照也已确认 COM/MID 丝印。用户随后报告已按[共地接线](../hardware/button-wiring.md)连接主板 GND、屏幕 GND 和按键 COM，MID 接 GPIO14；计数程序已烧录且 USB 状态正常，实际按压验证待回报，见[按键启动记录](button-bringup.md)。

## 哪些孔相通

面包板是带内部金属连接片的接线座，不需要编程，也不会自行供电。对于常见 a～j、数字排号的板型：

- 同一编号的 a～e 是一组；f～j 是另一组。中间沟将两组隔开。
- 相邻编号之间不相通。例如 a5 与 e5 相通，a5 与 a6 不相通，e5 与 f5 也不相通。
- 两侧带红蓝标记的长条是电源轨；红蓝只是标记。左右两侧不会自动相连，有些电源轨中部还分段。具体连续范围应按实物确认；有万用表时可在断电状态测通断。

例如，一根线把信号送入 a5，另一根线从 e5 引出，等同于用这一组内部金属片把两根线连接起来。屏幕这类单排针模块，每个不同信号必须落在独立孔组，不能把几根针插进同一个五孔组。

参考：[SparkFun 面包板结构说明](https://learn.sparkfun.com/tutorials/how-to-use-a-breadboard/all)。

## 第一次摆放与电源分配

1. 拔掉 USB，断电后再摆放和改线；保留已经接好的摄像头排线。
2. 主板可先放在绝缘垫上，用母对公杜邦线连接：母头套主板排针，公头插面包板。这样不用强压较宽的主板，也不会被它遮住所有接线孔。
3. 如果插入主板，两排排针应处在中间沟两侧，各针落在不同孔组；没有可用余孔时改用杜邦线引出，不强行弯脚。
4. 先只分配电源：主板明确标注的 `3V3` 接面包板一侧 `+` 轨，`GND` 接同侧 `−` 轨。用红线和黑线区分，暂不接模块、不上电。
5. 屏幕与按钮确认后，共用这一路 3.3 V 参考和 GND。不要把主板的 `5V` 引到计划使用的 3.3 V 电源轨。

当前八针导航按键板采用 COM 接 GND、MID 接内部上拉输入的方案，不接 VCC；这次共地不需要使用电源轨，也不需要将 3V3 引到面包板。

## 接模块前还需确认

- 屏幕背面：型号／版本、供电标记，以及每个排针旁的文字。商家资料中既有 `GND VCC SCL SDA RST DC CS BL`，也有不同顺序、没有独立 RST 的版本。
- 绿色五向按键模块：正面已确认 `COM UP DWN LFT RHT MID SET RST`；具体 PCB 版本与触点导通尚未实测。
- 面包板全貌：确认接线区方向、编号和电源轨分段。

已知占用来自当前跑通的相机固件：GPIO4～13、15～18 为摄像头信号，GPIO19／20 用于原生 USB。商家原配屏幕接线使用 GPIO19／20，不能直接照搬到当前方案；Flash／PSRAM 引脚及启动配置引脚也需避开。项目屏幕分配已记录在上述接线表中，中心键分配到空闲 GPIO14。

引脚限制参考：[ESP32-S3 GPIO 官方说明](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/gpio.html)。

## 验证顺序

1. 按钮输入：先验证一个键按下和松开的串口输出。
2. 屏幕输出：先验证纯色和文字，确认接线、方向与背光。
3. 联动：按钮每按一次，屏幕计数加一。
4. 再接回摄像头，实现按钮触发拍照和屏幕显示。

屏幕基本显示已完成验证；按钮及相机与屏幕联动尚未验证。新增模块接线前先确认针脚和供电，断电后再改线。
