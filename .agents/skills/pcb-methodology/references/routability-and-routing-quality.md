# 可布性规划与布线质量检查

用于新板、重布局、批量布线和异常路径评审。检查范围随改动范围收缩，已有同版证据直接复用；此流程不扩大用户授权、不改变选定工具，也不要求每个阶段再向用户确认。

## 布线前：证明布局可布，而非仅能摆下

在已有项目设计文档和板图中记录以下内容，不另建重复清单：

- **设计输入**：真实封装和引脚、固定／可移动器件簇、层叠、机械与天线禁布区、制造规则、电源与保护条件。规则写清来源、适用对象及哪些已进入 EDA、哪些需补充检查；未知量只阻塞依赖它的定案。
- **跨区通道图**：标出实际端点、引脚出口、可用图层、通道边界、瓶颈和供电／返回路径。按网络关联比较相邻引脚及同向连接的共同通道，不为排列整齐强迫无关信号并行。板上空白需扣除机构与净空，不能自动记为可布空间。
- **实际试布**：先验证电气关键回路，再选受拥挤影响的跨区连接试布，覆盖主要瓶颈；不因一个 USB 小区通过就冻结全板摆放。试布使用最终拟用的线宽、间距和过孔规则，不能先用小孔穿过再统一放大。
- **通过依据**：在保存的候选上展示路径、剩余通道、真实填铜及关键回路关系，列明不可兼得的取舍。出现无法解释的多次换层或供电返回退化时，先比较通道、顺序和相关器件簇位置，再固定受影响布局。

没有固定的全板布线顺序：电气敏感关系优先，其他网络按瓶颈安排。低速信号也需要出口和通道，但不能为其短直而破坏去耦、开关回路、保护路径或天线净空。

## 布线中：按批次检查路径和返回

每个功能区或连贯批次完成后，用当前几何检查下列项目；不要等用户指出走线异常。复用已有工具，只有缺失检查确实反复需要时才新增脚本。

| 观察到的现象 | 需要核实的事实 | 下一步选择 |
| --- | --- | --- |
| 一个普通信号有多个过孔 | 区分每网总孔数与两个指定引脚之间的串行换层；多分支网不能直接按总数判错 | 追踪实际路径，标出每次换层绕开的对象；无必要性证据的路径进入局部比较 |
| 短距离换层又换回 | 原层是否仍存在异网焊盘、明线、孔、禁布区或必须保留的返回通道 | 若障碍仍在，比较两网的顺序／通道；若没有，验证同层简化候选，而非直接删孔 |
| 端点相邻、同向信号却分走板两侧 | 固定接口、引脚出口、通道容量和电气关系是否迫使分开 | 比较共同通道；不自动加等长要求或改引脚，也不为少孔拉长关键回路 |
| 路径明显绕远 | 指定端点的实际路径长度、可行障碍；区分单路径与全网线长 | 直线距离只是几何下界。先验证替代路径，不能用线长／直距比直接宣判失败 |
| 重铺后地仍连通但形状变差 | 命名负载／电容到源端的地路径、狭窄截面、换层和绕行，及本批信号造成的变化 | 修复实际瓶颈或分配通道；不能只数地孔、地铜面积或连通分量 |

对供电和保护返回，记录命名起终点、瓶颈位置及实际宽度，并依据电流、器件布局要求和制造能力判断。铜区内缩试验可帮助定位细颈，但内缩距离不是通用合格阈值，几何路径也不是电流／阻抗仿真。连通图不能单独证明返回质量；信号铜未变时，其参考地仍可能被别的布线破坏。

使用自动布线器或自编路由脚本前，核对其实际控制项：线宽／间距、图层、过孔代价、布线顺序、已有线路是否可调整，以及是否有后续简化。只支持避障接通的脚本不视为已优化布局；参数变更须通过局部结果验证，不凭提高过孔代价保证孔会合理减少。

不设置无来源的统一“最多几个孔”“最大绕行倍数”或覆铜比例。这些统计用于定位值得评审的路径，不代替器件电气和制造约束。

## 采用修改前与交付时

候选直连或删孔方案须重新铺铜、复核地返回／净空、逐脚网络与原生 DRC，并按主 skill 保存重开核对。异网离散铜不冲突只是候选可行性的部分证据，不能提前写为优化成功。

在同一版本记录四类结论：

| 结论 | 所需证据 |
| --- | --- |
| 连接与几何正确 | 网表、原生 DRC 分类、真实铜连通；独立检查和原生结果冲突时先查明原因 |
| 布局／路径质量可接受 | 关键区与拥挤通道的分层图、异常路径解释或前后比较、命名供回电路径及取舍 |
| 制造条件满足到哪一步 | 同版 Gerber/BOM/CPL、PCB／SMT DFM 及实际工厂条件；网页通过不替代电气质量 |
| 实物功能已验证到哪一步 | 实测记录；尚未测试的 USB、温升、显示、射频与装配保持待验证 |

若同类修复反复破坏邻近连接或返回通道，不继续逐点补孔：保留当前候选作为基线，定位布局、顺序、路由能力或规则冲突的根因，做有限局部方案比较。能够继续的独立工作照常推进；制造诊断可在明确标注未闭合项时开展，不以追求完美外观无限延后 DFM。流程新增本身不触发全面重做。

## 已发生的案例与一手参考

- [NFC D 三条信号路径](../../../../projects/nfc-business-card/hardware/d-signal-planning-review.md)：绑定快照的实铜拓扑追踪确认串行换层 7／7／6 次；发现两处同层简化候选，也定位了一处真实的 CHG_SDA 障碍。候选尚未在该报告中验证，不作通用孔数上限。
- [NFC D 返回路径](../../../../projects/nfc-business-card/hardware/board-review-d.md#回流连通通过质量未通过)：全网连通后仍发现充电器地返回依赖约 0.029 mm 细颈。该历史值说明检查缺口，不作为其他板的设计阈值。
- [Cadence 约束管理流程](https://resources.pcb.cadence.com/i/1532922-orcad-x-constraint-management-guide-part-5/3)：约束、层叠和布线前规划进入器件摆放／布线之前的设计流程；本文件的阶段检查是本仓库根据失败案例制定的做法，不冒称厂商强制流程。
- [Freerouting 布线设置](https://freerouting.org/freerouting/manual/routing-options)：图层方向、过孔规则／代价及布线后线长／孔数优化是不同控制项。只有实际采用该工具时才按当前版本核实，不默认安装或切换工具。

改用 KiCad 后同样执行以上检查。EDA 工具能力、AI 的规划文字与已验证的板级设计结果分别记录。
