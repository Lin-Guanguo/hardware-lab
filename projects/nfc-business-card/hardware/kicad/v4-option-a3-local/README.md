# NFC Card V4 A3 局部修复候选

## 当前确定方案

从保存重开的 A2 复制，保留旧对照；本轮没有整板自动重布。打开 [NFC-Card-V4.kicad_pro](NFC-Card-V4.kicad_pro)，相对项目库随目录保存。PCB、原理图、规则及装配信息均为原生文件。

**尚未完成整板，不可投厂。**61 个必要地焊盘已连通；GND 未连接 9→0，其它 7 项仍未连接。672 段／98 孔，ERC 0、DRC 58、parity 0。保存重开指纹一致；原厂焊盘、机械／天线基准、0.8 mm 双层和采样功能保留。

只有 R1/R2 在原中心翻转、C25 ADC 出口与明确地返回修复被保留。TS/PG 会切断 C4 地的试案已撤回；其它未通过的局部方案没有写入 PCB。文件名为 `*-plan.json` 的内容可能是失败试案，必须查看 `failures` 与对应记录，不能视为待直接应用的修改。

[报告、前后图、实际地分量及最小拆改范围](../../v4-option-a3-review.md)记录剩余 TS/MR、BUSY/VBUS、USB CC/D−、CS 的障碍；电气与制造待办未关闭。本轮未生成最终制造文件或执行 A3 PCB/SMT DFM。下一步是有对象的局部组联合修复，不能把当前铜锁死后再扫整板顺序。

[A2 起点](../v4-option-a2-full/README.md)和旧 A／phase1/2/3 均保留。[可复现命令](../../v4-option-a3-review.md#图与复现)可在新目录由 A2 重建本轮已接受的原生增量。
