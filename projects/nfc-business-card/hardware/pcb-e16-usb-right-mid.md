# E16 右侧中部 USB 研究

## 当前结论

更新于 **2026-09-22**。USB 可以规划到右侧中部，但不能在 E15 上只拖动 `J1` 完成。右侧中部同时受 `U1` 主控、去耦器件、板右边界和 NFC 保留区约束，需要作为一套新的板框、器件排布和走线方案重排。

本轮从 E15 复制出独立研究图页 **E16 Right-Mid USB Study**（PCB UUID `2fe84861daa4cba5`），将 USB 小组试放到右侧中部；E15（UUID `4991220fd7f692a5`）没有被这次试验污染。E16 已保存、关闭并重开，位置变更仍在；最后已恢复打开 E15，E15 保持 4 条线、2 个过孔的 `USB_CC2` 首段。

## 试放位置与结果

试验位置使用 EasyEDA 原始坐标：

- `J1`：`(3092, 700)`，旋转 `270°`，约为 `(78.54, 17.78) mm`。
- `R1`：`(3057, 800)`；`R2`：`(2877, 800)`。
- `U5`：`(2857, 600)`，旋转 `180°`；`U6`：`(2907, 550)`，旋转 `270°`。
- `U1` 保持 `(3000, 500)`，约为 `(76.20, 12.70) mm`。
- 为避免把 E15 的临时成果带入研究，E16 当前没有铜线和过孔。

在线 DRC 结果为 **30 个普通间距错误、12 个同封装间距错误、200 个连接错误**：

- `J1` 封装与右上 NFC 禁布区发生 1 项 `Device to Prohibited Region` 冲突。
- USB 焊盘与 `U1` 主控焊盘发生 9 项间距冲突，主控/USB 焊盘还贴近右板边，产生 13 项板框到焊盘冲突。
- 其余冲突包括 USB 焊盘与通孔焊盘、孔与焊盘之间的边界问题；12 项同封装错误是原有 J1 封装检查项。
- E15 的 NFC 禁布区约为 `x=60–82 mm、y=24–50 mm`。把 USB 小组继续下移会让整个小组进入该区域，不能靠简单平移解决。

## 下一步开工条件

如果继续采用右侧中部 USB，应从 E16 另起一轮布局评审：

1. 先冻结右侧 USB 外壳开口、插拔包络和新的 Layer 11 板框入口。
2. 将 `U1`、去耦和 USB 小组一起重新排布，给 J1 焊盘和右板边留下制造间距。
3. 重新评审 NFC 保留区和天线位置，不能直接侵入现有 `x=60–82 mm、y=24–50 mm` 区域。
4. 在新排布上重新导入 `Board1_1/Schematic1` 网表，再按 CC、DP/DM、VBUS 和 GND 顺序布线。
5. 通过机械核对、保存重开和分类 DRC 后，才决定是否替换 E15 的底边 USB 方案。

在上述条件完成前，当前正式开工入口仍是 E15 的底边中部 USB；E16 仅作为右侧中部方案的可追溯研究副本，不作为制造稿。
