- 快照中的 DRC 基线为 8 个普通间距错误、12 个同封装间距错误和 200 个连接错误，共 220 项。它们只用于开工前对照，不代表已完成的在线 DRC 结果。
- 本轮通过本地 Bridge 完成了客户端只读核对，没有通过 API 写入或改动工程。

## USB 机械基线

`J1` 当前封装为 `USB-SMD_USB4500-03-0-A`。 [GCT USB4500 产品资料](https://gct.co/connector/usb4500) 将该系列标为 USB 2.0 Type-C、水平侧插、中置安装；页面给出的连接器本体长度为 6.50 mm，产品高度为 3.16 mm，偏移高度为 0.80 mm。它们是供应商宣传/目录参数，尚未替代手上实物的卡尺测量和外壳试装。

- E15 当前底边缺口深度约 6.5 mm，与目录中的连接器本体长度处于同一数量级，可作为暂定机械入口基线。
- E15 当前缺口宽度约 13 mm。公开资料中的推荐 PCB 开口尺寸仍需结合具体版本图纸核对，暂不据此直接改板框。
- 项目已有 [USB4500 槽边距复核](usb4500-clearance-review.md)：原封装焊盘到槽后边约 0.20 mm，按当前公开工艺下限可继续保留，但这不是订单级确认，也不替代 E15 的外壳试装。
- 因此，当前 8 项普通板边间距错误和 12 项 J1 同封装间距错误先按“待机械确认”分类；不为了清零 DRC 而盲目缩小缺口、移动 J1 或删除封装外形。需要优先核对的是板边到外壳窗口、锚脚和插拔包络。
- 在拿到实际连接器或确认外壳开口后，再决定 Layer 11 是按连接器本体开口、插头插拔包络还是外壳窗口留量重画。

## 在线 API 核对

重启 EasyEDA 后，API Gateway 已在本地 `49620` 端口连通。在线读取确认：当前文档仍为 E15（`documentType=3`，UUID `4991220fd7f692a5`），工程树中的 E15 `parentBoardName` 为空，`Board1` 仍关联 `Schematic1`；没有发生隐式绑定。

在线 DRC 与快照一致，共 220 项：

- 8 项普通间距错误，其中包含主板框与 R1、J1 通孔的边缘冲突。
- 12 项同封装间距错误，全部集中在 J1 封装外形与其 USB/电源/地焊盘之间。
- 200 项连接错误，说明 E15 仍是完全未布线的布局起点；USB、充电/电源、按键、屏幕和主控网络都还没有铜线连接。

因此下一步的实际顺序已经收敛为：先确认 USB4500-03-0-A 的实际外形/开口包络，按机械依据处理 J1 与 Layer 11 的边界冲突；再确认 E15 是否继续保持独立 PCB 图页；之后才开始 USB 和电源网络布线。在线 API 只读核对已完成，本轮没有写入工程。

## 开工顺序

1. **先统一基准。** 在 EasyEDA 中确认 E15 是否关联现有 Board/原理图；明确 84 × 52 mm 是 PCB 板框还是含外壳边缘的目标尺寸。未确认前不继续画板框和外壳。
2. **锁机械入口。** 根据实际 J1 封装、插拔方向和外壳边界重画底边中部 USB 开口；同时确认 Layer 11 板框、锚脚、槽边到铜和工艺边。
3. **放真实电池边界。** 先使用交付最大包络，而不是只使用 30 × 12 × 3 mm 标称值；包络要包含保护板、胶带、焊点、引线和鼓胀余量。未取得供应商数据前，电池只能作为可替换的保守占位。
4. **验证连接关系。** 从原理图重新导出网表，在 E15 中核对元件关联、封装和关键电源网络；记录未布线数量作为新基线。
5. **按风险布线。** 依次处理 USB DP/DM、CC1/CC2、VBUS、GND 回流、充电/SYS/BAT、3V3、主控 USB 和屏幕关键时序；每个区块保存、关闭、重开并重新跑 DRC。
6. **再同步 CAD。** 只有板框、J1、屏幕/FPC、电池包络和按键位置冻结后，才从 E15 坐标生成外壳开口、支撑和装配公差。现有 E14 V1/V2 只作验证样件。

## 本轮放行条件

- E15 图页与原理图 Board 关联明确，保存重开后元件和网络一致。
- PCB 板框、USB 缺口、屏幕/FPC 区、电池包络和 NFC 净空使用同一坐标基准。
- 关键 USB/电源网络有可审查的走线，DRC 结果按类别记录；未解决的连接或板边错误不能被标记为完成。
- 实际电池和屏幕到货前，不冻结厚度、壳体卡扣或供应商制造文件。

本阶段不生成 Gerber、Excellon、最终 BOM/CPL、生产 STEP 或可直接打印的外壳。E14、E13、E9 及其他历史工程保留用于回退和比较。
