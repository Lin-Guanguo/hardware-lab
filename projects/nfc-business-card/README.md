# Programmable NFC Business Card

中文名：可编程 NFC 墨水屏名片。项目目录：`nfc-business-card`。

目标：银行卡大小、厚度不超过 5 mm 的可编程名片。按键切换身份，墨水屏显示当前身份，手机或兼容读卡器读取对应 NFC 链接。

**当前建议采用 nRF52840 + 可编程 USB-C + 1.54 英寸黑白墨水屏 + 三个按键 + 约 40–60 mAh 薄电池。** 用户新增 USB 编程要求后，原 nRF52832 + 日常 SWD 方案退为备选。NFC 使用主控内置的 NFC-A Type 2 标签功能，按键修改 NDEF 内容。用户希望降低复杂度，当前优先评估成品小板平铺、飞线连接与打印壳固定，定制 PCB 留作备选。

这是待评审的工程路线，尚未绘制原理图、PCB 或可生产外壳，未采购、构建或实测。用户发现成品卡套内腔偏低，希望尝试透明树脂打印；下一步优先验证 SLA 薄壁与透明后处理样片。≤5 mm 仍是目标，全打印双壳尚未证明可达，打印框/底壳配透明薄片保留为备选。

## 已确认需求

| 项目 | 约束 |
| --- | --- |
| 外形 | 约 86 × 54 mm，可在设计阶段微调；装配后所有突出物计入 ≤5 mm |
| 外壳 | 希望半透明，可 3D 打印；屏幕、电池尽量平铺 |
| 交互 | 小墨水屏，几个按键或五向按键 |
| NFC | 自己按键切换对外呈现的名片/身份，让手机或读卡器读取 |
| 电池耗尽 | 允许 NFC 暂停，充电后再用；不要求无电仍能读 |
| 内容更新 | V1 编译进固件，重新烧录修改；不做手机配置端 |
| USB | 必须有可编程 USB 口；按 USB-C 日常刷固件并供电/充电规划，SWD 仅首烧/救援 |
| 软件安装 | 先讨论后安装；本轮没有安装软件 |

“身份”在 V1 指名称和链接等应用数据；不等同于模拟任意门禁、支付凭据或改变任意读卡系统认定的身份。

## 可选路线

| 选项 | 组成 | 优点 | 主要代价 | 建议 |
| --- | --- | --- | --- | --- |
| A：薄模块备选 | nRF52832 / MDBT42V-P512KV2，512 KB Flash / 64 KB RAM | 模块标称高 1.50 mm，NFC 满足需求 | 没有原生 USB；若加 USB 转串口需额外硬件与 bootloader | 不再作为主方案 |
| B：原生 USB | nRF52840；MDBT50Q-P1MV2 为已核对候选，1 MB Flash / 256 KB RAM | 同时具备 USB 与 NFC | 该模块标称高 2.00 mm，需重做 USB/外壳预算并实现下载流程 | **当前主路线，模块料号未冻结** |
| C：掉电可读 | 低功耗 MCU + NTAG I²C Plus | 无电可读最后一次写入的内容 | 多一颗芯片与总线协调，当前需求用不到 | 暂不采用 |
| D：极限定制 | 裸 nRF52 + 全定制电源/天线 | 可降低模块占用 | 首板难度与调试工作更多 | A/B 无法达到机械目标时再评估 |

模块尺寸、官方来源与限定条件见 [器件选项](hardware/component-options.md)。NFC 行为及固件状态见 [架构](docs/architecture.md)。

## 当前结论与下一步

1. **优先验证成品 nRF52840 小板 + 飞线。** 先查 XIAO 类主控板、匹配的屏幕驱动板和电池的完整高度，平铺排布后再定采购组合；USB 下载与 NFC 必须联合验证。EN04/DK 保留作桌面调试备选，定制 PCB 不作为必经步骤。
2. **外壳优先试透明 SLA 树脂，先样片再整壳。** 用户提供的材料页标称最小壁厚 0.8 mm、精度 ±0.1 mm，实际薄盖平整度与后处理尺寸待验证；全打印若无法满足 ≤5 mm，再比较透明薄片与打印框。早期 nRF52832 的图表只保留作比较，USB 版必须重新排布主控和插座。
3. 下一次讨论先确定软件安装范围、打印服务可交付的壁厚/公差，以及三按键/五向键偏好。暂按三按键进行布局研究。
4. 获得电池完整包体图、屏幕完整 FPC 图和贴片可制造性反馈后，才冻结 BOM 与外壳。
