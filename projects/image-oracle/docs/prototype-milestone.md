## 当前边界

- 结构仍是开发板、现成模块、面包板共地和杜邦线连接，桌面体积大、线材分散；尚无定制 PCB、焊接成品或外壳。
- 五向按键目前只接 COM 与 MID，其他方向、SET、RST 未接入；其余传感器、音频等模块未通电验收。
- 答案是冻结缩略图的确定性哈希映射；照片仅在 RAM，断电丢失。尚未扩展答案库或持久保存。
- 已有短时间实机回归和用户体验验收；长时间连续运行、专项长按测试、更高分辨率及整机功耗测量未完成。
- 本阶段完成的是交互功能原型；尺寸、固定方式、连接可靠性和成品装配将进入下一阶段处理。

## 路线一：拼接更多传感器，继续实验

目标是利用现有器件探索更多输入和互动。候选来自已购清单：SHT30 温湿度、GY-302 光照、触摸模块、旋转编码器，以及五向按键的其余功能；具体型号、工作电压和可用 GPIO 在每次实验前核对。

每次选一个模块，先完成独立读取或事件测试，再决定是否接入屏幕页面；保留当前原型作为回退基线。每个实验记录接线、驱动依赖、实际命令、读数和验证结论，接线图沿用现有格式。不要因为增加传感器，就默认改变“图像是 Oracle 唯一变化输入”的规则；若要混入环境数据，应另行明确算法版本。

完成一个实验的标准是能稳定读取或响应、交互仍及时、有可复现记录。后续再决定哪些功能值得保留到紧凑版本，不预先把全部模块纳入最终装置。

## 路线二：焊接、定制电路板与 3D 打印，做紧凑装置

目标是把已经能工作的交互收进可拿起、可固定、可维护的小装置，减少桌面杜邦线。

推进顺序先作为工作草案记录，具体结构和工艺待启动此路线时验证：

1. **确定保留的功能与布局。** 测量当前开发板、屏幕、摄像头、按键和接口的实际外形、孔位及高度；决定显示方向、镜头位置、按键位置、USB 插拔与复位操作空间。
2. **整理连接与装配方式。** 明确哪些模块可插拔、哪些连接焊接固定；比较短线束、洞洞板／转接板和承载现有模块的 PCB。更换接法前整理原理连接表和引脚占用。
3. **定制 PCB。** 在功能和布局相对稳定后绘制原理图与 PCB，逐项核对电源、接口和模块尺寸，再进行打样、焊接和通电验证。是否进一步用模组或芯片替代现成开发板，留待体积需求明确后决定。
4. **3D 打印外壳。** 先验证安装框架、开孔和固定点，再结合实际板卡／线束调整外壳；记录模型、版本和试装问题。开始有真实设计内容时才创建 `enclosure/`。
5. **整机复测。** 验证装配后取景、显示、按键、USB 编程、稳定供电和持续运行，并确认连接固定与拆装维修是否可行。

两条路线可以交替进行；传感器实验保留扩展空间，紧凑版本在绘板前确认本次要保留的功能。本次只记录方向，没有选定制造服务、材料、预算或最终尺寸，也没有发起采购或制作。
