# NFC 备选调研：屏幕后置与断电可读

**最新决定（2026-09-20）：用户确认不推进断电可读。** 继续使用 nRF52840 内置 NFCT，优先薄度及银行卡以内的成品外形；屏幕后置线圈/隔磁片仍作后一版备选。以下是历史调研，不是当前执行计划；当前工作见[紧凑排布比较](../enclosure/compact-layout.md)。

记录日期：2026-09-20。用户确认将“屏幕后置线圈、背面碰卡”保留为后一版备选，并重新询问动态标签的断电可读能力。当前 Bottom-USB 排布与 nRF52840 内置 NFCT 方案均未替换，未采购或验证新器件。

## 两个可以分别选择的方向

| 方向 | 改善什么 | 主要代价 |
| --- | --- | --- |
| 屏幕对应位置的背面 FPC 线圈 + 铁氧体片 | 有机会释放当前独立的 23 × 25 mm NFC 区 | 重做叠层、引线和天线调谐；从背面读取；须验证屏幕、PCB 和壳体的影响 |
| 主控 + 动态 NFC 标签 | 电池断开后仍可读取已成功写入的名片链接 | 增加标签芯片、I²C 与供电设计；处理 EEPROM 更新、接口并发及屏幕一致性 |

两条路线在技术上可以分别验证。更换标签芯片不会自动缩小线圈或消除金属净空要求；这也是本次不推进动态标签的取舍依据。

## 屏幕后置和隔磁片采购

候选层次，从手机所在的背面向屏幕正面看：**手机 → 非金属背壳 → NFC 线圈 → 铁氧体片 → PCB／屏幕**。铁氧体位于线圈与内部导电材料之间；最终线圈引出、覆盖范围和匹配按实物设计。该层次不承诺隔着屏幕正面也能读取。

当前模型 PCB 底面 z = 0.9 mm，背壁顶面 z = 0.8 mm，名义间隙仅 0.1 mm。需要重排局部结构，不能把新材料直接加入现有缝隙。屏幕规格未提供 13.56 MHz NFC 叠放验证。

隔磁片有标准料号和单片零售渠道，不必先定制。已核实的采购线索：

- Würth **WE-FSFS 364004**：60 × 60 mm，原厂分别列出约 0.1 mm 铁氧体、0.03 mm PET、最大 0.05 mm 胶层；DigiKey 列出的总体厚度为 0.18 mm。原厂给出 13.56 MHz 的磁导率与损耗数据。[原厂规格](https://www.we-online.com/components/products/datasheet/364004.pdf)、[DigiKey 商品页](https://www.digikey.com/en/products/detail/w%C3%BCrth-elektronik/364004/4692709)。它是可采购性示例，尚非本项目选定材料；中国配送、到手价及裁切后效果未确认。
- 国内搜索词：`NFC 13.56MHz 铁氧体 隔磁片 背胶`、`NFC 抗金属片 可裁剪`、`NFC FPC 天线 带铁氧体片`。本轮没有核实具体淘宝店铺库存或质量。
- 选购时确认 **13.56 MHz 用途、含胶/保护膜总厚度、可用面积和裁切方式**。仅标“吸波材料”“防消磁”或“无线充电隔磁片”不能证明适合该 NFC 线圈。原厂选材说明要求在工作频率有较高磁导率和低损耗：[Würth 应用资料](https://www.we-online.com/en/components/media/o124588v410%20WE-FASFSFS%20Design%20Kit%20Brochure%20304999BR%20%28rev1%29.pdf)。

标签和导电材料的相对位置会改变天线性能，必须在完整装配里验证：[ST AN2972](https://www.st.com/resource/en/application_note/an2972-how-to-design-an-antenna-for-dynamic-nfc-tags-stmicroelectronics.pdf)、[TDK 铁氧体说明](https://www.tdk.com/en/tech-mag/ferrite02/008)。隔磁片厚度不能直接当作包含线圈与绝缘的完整堆叠厚度。

## 动态标签如何实现断电可读

候选优先研究 **NXP NTAG I²C Plus（NT3H2111／NT3H2211）**，沿用 Type 2 / ISO14443A 路线；ST25DV04KC 是 Type 5 / ISO15693 的备选，协议与读卡器兼容性需另核。此优先级是本项目判断，尚未冻结封装、库存或 BOM。

1. 有电时，按键让主控选择身份，通过 I²C 把 NDEF 链接写进标签的 **EEPROM**，检查写入完成并读回验证。
2. 电池断开、主控不工作时，手机的 NFC 场给标签供能，读取 EEPROM 中已保存的链接。
3. 没电时仍能被读取，但本设计的按键切换和屏幕刷新需要恢复供电。

NXP 明确支持关闭设备电源后从 RF 接口读取 EEPROM：[产品说明](https://www.nxp.com.cn/products/rfid-nfc/nfc-hf/connected-nfc-tags/ntag-ic-plus-2k-nfc-forum-type-2-tag-with-ic-interface:NTAG_I2C)。**不能只使用 SRAM 镜像或透传来保存最终名片**，SRAM 依赖 VCC，不能保留断电后的内容。[数据手册](https://www.nxp.com/docs/en/data-sheet/NT3H2111_2211.pdf) §8.3.4、§8.3.11、§11.2。

RF 侧可配置为普通手机可读、写入受保护，I²C 侧保留主控写入权限；具体配置需验证，不能把永久锁定全部数据当作动态切换方案。它也不是普通 NTAG213／215／216 贴纸所提供的主控 I²C 接口。

## 采用前需要完成的工程工作

- 标签芯片连接自己的天线和匹配网络，不与 nRF52840 的 NFC1/NFC2 并接同一线圈。nRF52840 可以继续作主控，之后也可重新评估只满足 USB、屏幕和按键需求的主控；本轮不换芯片。
- 检查动态标签的独立供电和 I²C 上拉/断电状态。NTAG I²C Plus 在 VCC = 3.3 V、I²C 空闲时的典型电流约 195 µA，不能当作常供电零功耗器件。可以评估仅更新时给有线接口供电，但须核总线隔离、反向供电和上电时序。见数据手册 §13，以及 [NXP 勘误](https://www.nxp.com/docs/en/errata/ES_NT3H2111_2211.pdf)；尚未完成逐项实现审查。
- 只在确认切换时更新 EEPROM，处理 RF/I²C 存储器仲裁、写入中断和恢复。断电保留有效数据不代表任意多页写入都具备事务原子性。
- 屏幕显示与 EEPROM 是两个独立状态。刷新或写入途中断电可能造成显示和 NFC 内容不一致，现有内置 NFCT 的更新流程需要另行改写，不能直接声称断电一致。
- 优先验证：写入身份 A → 读回 → 断开电池和 USB → 多手机读取；再验证更新为 B、受保护 RF 写入、更新过程中断电、屏幕与 NFC 内容一致性。无电读取不承诺同时给 MCU 或六色屏供电。

两条路线都尚无本项目实测结果。用户已明确当前不推进动态标签；后置天线留作后续空间优化研究。
