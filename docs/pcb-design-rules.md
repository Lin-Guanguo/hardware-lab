# PCB 设计规则索引

这份文档回答一个问题：**哪些规则是 DRC 抓不到、但会让板子出问题的？**

它列出规则、阈值、一手来源，以及每条规则对**本仓库的板子类别**（2 层、0.8 mm、USB 全速、射频在模块内、线性充电 + 升压变换）是否成立。它不复制上游规则原文，只做索引与适用性判定——完整规则定义读 `upstreams/` 里的原文。判定的原因比判定本身重要：写明"不适用"和写明"适用"同样有价值，否则会花力气去做不相关的事。

约束层级（硬约束与可交易目标的划分）与变更门禁见 [PCB 方法论 skill](../.agents/skills/pcb-methodology/SKILL.md)。

## 为什么需要这份索引

EasyEDA 的原生 DRC 只检查几何间距与连接：它是必要条件，不是充分条件。这一点本项目已经反复踩到并写进记录——[整板评审](../projects/nfc-business-card/archive/pre-r1/hardware/board-design-review.md) 写明"不会以 DRC 剩余数量作为改层依据"，[E16 记录](../projects/nfc-business-card/archive/pre-r1/hardware/pcb-e16-usb-right-mid.md) 写明"这只是几何与额定电流的估算：压降、去耦回路、升压瞬态和地回流阻抗仍需在实物上测"。

已发生的实例（本索引存在的理由）：`C3` 是 BQ25186 的 BAT 引脚电容（2.2 µF），在 E16 的 USB 排版中被归入"USB 小元件"搬到 (71.90, 20.60)，离 U2 的 BAT 焊盘 24.49 mm（E15 时在 (49.53, 22.86)，约 4.7 mm）。原生 DRC 0 间距、逐引脚网表 0 差异、连通性 0 断网、制造包 `ok=true` **四项全过**——因为它是一处布局意图错误，没有任何一项检查会问"这颗电容该在哪"。DC-001 一次就把它标出来了，随后按本索引的流程搬回 U2 旁 (49.60, 21.60)，实测 2.04 mm，规则从 CRITICAL 变为通过（见 [E16 记录](../projects/nfc-business-card/archive/pre-r1/hardware/pcb-e16-usb-right-mid.md)）。

## 覆盖状态图例

| 标记 | 含义 |
| --- | --- |
| ✅ 自动 | 已由本项目检查器实现，可复跑 |
| 🔒 阻塞 | 需要覆铜几何；快照导出尚未采集铜箔铺铜对象 |
| ✋ 人工 | 需要器件资料或人工判断，无法从几何推出 |
| ⬜ 待实现 | 判据所需几何已具备，但检查器还没写 |
| — 不适用 | 规则前提在本板类别下不成立 |

检查器：[check-e16-emc.py](../projects/nfc-business-card/archive/pre-r1/scripts/check-e16-emc.py)（E16 专用；板级无关的通用化等第二块板再做，不预先抽象）。

```bash
cd projects/nfc-business-card
python3 scripts/check-e16-emc.py --json /tmp/e16-emc.json

# 校验"本表声称自动覆盖"与"检查器真的实现"是否一致
python3 tools/check-rule-coverage.py
```

两条关于这张表可信度的说明：

- **覆盖声明由机器校验。** 标 ✅ 却没有对应实现的条目，属于过度声明——它会让板子看起来被审过而实际没有。这条守卫存在是因为真的发生过一次：`BE-001`、`BE-003`、`IO-001`、`DP-002` 曾标为自动而无人计算，`DP-002` 已因此降为 ✋ 人工。
- **器件角色是声明的，不是从几何推出来的。** 快照只能给出封装，给不出功能，所以检查器里的 `EXTERNAL_CONNECTORS`、`PROTECTION_REFS`、`SWITCHING_INDUCTORS`、`SENSITIVE_REFS` 四张表是人工声明并在每条结论中一起打印。换板或换料号必须同步改这四张表，否则检查会静默答非所问。

## 铜箔与回流路径

| 规则 | 阈值 | 本板 | 说明 |
| --- | --- | --- | --- |
| [GP-001](../upstreams/kicad-happy/skills/emc/references/pcb-emc-rules.md) 信号跨越铺铜缺口 | 任一信号网络的参考面覆盖率 <95% | ✅ 自动（**仅供参考，非门禁**） | 已实现，但**结论暂不可信**：铺铜会沿每条走线留出间距，走线中心线永远落在铺铜为它挖出的间隙里，所以必须按"到最近参考铜箔的距离"判，而**走廊宽度是我定的**。取 0.5 mm 时 48 个信号网络里 45 个低于 95%——对一个地覆铜占 40% / 51% 的板子，这个结论不可信。症结是这个指标无法区分"真实平面开槽"与"平面被同层其它走线的间距穿孔"。标为参考项，**校准到已知有问题的板子之前不作为发现**。本板确实存在的两处开槽是 NFC 禁布区（设计如此）与 EPD 电容列 (x 44–58, y 25–45) |
| GP-003 地平面碎裂 | 地网络有 >3 个不连通岛 | ✅ 自动 | 实测顶层 **29** 个覆铜区域、底层 **14** 个（`analyze-e16-pour.py`）。区域数远超"3 个岛"的阈值，但**这 29 块是否都连到 GND 网络尚未逐一验证**——原生 DRC 报 0 未布通，而本项目的 `ground_reach` 尚不可信（见[E16 记录](../projects/nfc-business-card/archive/pre-r1/hardware/pcb-e16-usb-right-mid.md)）|
| GP-004 地填充率 | 地覆铜填充率 <60% | ✅ 自动 | 实测顶层 **40.0%**、底层 **50.7%**，均低于 60% 阈值。**适用性**：该阈值按专用地平面写；2 层板双面密集走线下 40–50% 属预期，其含义是回流通道被压缩，正是 `GP-001` 要查的，不宜单独当缺陷 |
| GP-005 多个地域 | 检测到多个地网络 | 🔒 | 本板单一 GND，预期通过；仍需覆铜确认无孤岛 |
| [RP-001](../upstreams/kicad-happy/skills/emc/references/pcb-emc-rules.md) 换层缺缝合孔 | 信号过孔周围 max(2 × 介质厚, 1.0 mm) 内无地缝合孔 | ✅ 自动 | 本板 2 层、介质 0.8 mm，阈值 1.6 mm。实测 120 个信号过孔中 93 个超过；其中 **22 个带快速边沿**。USB 对的 8 个换层孔离最近地过孔 **4.27–6.83 mm**。**适用性**：2 层板没有平面对，回流在两面地覆铜之间跳，全速 USB 的 15 ns 边沿下这条绕行只有 λ/1000 量级 |
| [VS-001](../upstreams/kicad-happy/skills/emc/references/pcb-emc-rules.md) 缝合孔间距 | 平均间距 > 2 × λ/20 | ✅ 自动 | 本板 48 个地过孔，平均最近邻 2.92 mm，阈值 6.0 mm（2×λ/20 @2.4 GHz）通过。最大最近邻 8.56 mm 出现在 (69.70, 2.60)，位于天线禁布区边缘，属有意留空 |
| BE-001 信号靠近板边 | 外层走线距板边 < 1 × 介质厚 | ✅ 自动 | 阈值 0.8 mm。实测 **798 段里 7 段**低于阈值，且**全部是直流或按键驱动的慢速网络**（`USB_CC1/CC2/VBUS` 在 USB 缺口内 0.504 mm，`KEY_PREV_N` 沿电池开口边缘 0.400 mm）——0 段带快速边沿。注意与槽边铜距 0.20 mm 是两条不同规则 |
| BE-002 地覆铜环 | 板周长 <90% 在 2 mm 内有地覆铜 | ✅ 自动 | 实测覆铜距板边西/南/东/北 = 0.50/0.15/0.50/0.50 mm（顶层）与 0.50 mm（底层），全部在 2 mm 内，通过 |
| BE-003 连接器区缝合孔 | 连接器 10 mm 半径内孔距 > 2 × λ/20 | ✅ 自动 | 实测 **J1 的 10 mm 内只有 1 个地过孔**（且在 9.08 mm 处，实际属 U1 区域），5 mm 内 0 个。**适用性**：阈值按连接器最高频信号的拐点频率算，USB 全速 15 ns 边沿对应约 23 MHz，2×λ/20 ≈ 620 mm，远大于板子——这条对全速连接器**不构成约束**，数值本身不是缺陷 |
| EE-001 板腔谐振 | 谐振频率落在辐射源 ±20% | 🔒 | 2 层 0.8 mm 无平面腔；本板实际意义有限，列为信息项 |

## 去耦与电源

| 规则 | 阈值 | 本板 | 说明 |
| --- | --- | --- | --- |
| [DC-001](../upstreams/kicad-happy/skills/emc/references/pcb-emc-rules.md) 去耦距离 | 5 mm 警告 / 8 mm 严重（**焊盘到焊盘**） | ✅ 自动 | 必须量焊盘到焊盘。用元件中心到中心量会给 U1 报出假 CRITICAL（9.23 mm），实际 C5/C6/C7 → U1 的 VDD_3V3 焊盘是 4.40 / 3.75 / 4.12 mm，通过。**C3 由此暴露：21.90 mm**，随后修复至 2.04 mm |
| DC-002 缺去耦 | IC 10 mm 内无电容 | ✅ 自动 | 本板全部 IC 都在 10 mm 内（中心到中心，粗筛） |
| DC-003 电容远离过孔 | 电容焊盘到电源/地过孔 > 3 mm | ✅ 自动 | 供电类电容全部 ≤2.7 mm。电源变换类电容（C3 5.68、C11 4.24、C13 7.50、C19 4.12 mm）超阈值——它们不是高频去耦，但连接电感对开关回路的 EMI 同样重要 |
| SW-002 开关节点铜面积 | >25 mm² 中等 / >100 mm² 高 | ✅ 自动 | `EPD_SW` 铜箔 1.86 mm²，通过 |
| SW-003 输入电容热回路 | 三角面积（输入电容 → IC → 电感）>25 mm² | ✅ 自动 | U4→L1→C9 为 0.85 mm²，通过 |
| SW-001 谐波落入测试频段 | 开关谐波落在 30–960 MHz | ✋ 人工 | 需要 U4 升压的开关频率与边沿时间；数据手册可得 |
| PD-001..004 PDN 阻抗 | 反谐振峰超过 Z_target = V × 5% / (0.5 × I_transient) | ⬜ | 覆铜平面对已就位（顶层/底层各一块 GND），还缺逐电容的网络与 ESL/ESR 映射。2 层板无平面对，此项收益有限 |
| EF-001/002 EMI 滤波器截止 | f_sw / f_cutoff < 5 | — | 本板无输入 EMI 滤波器设计 |
| TH-001 MLCC 直流偏压降容 | 有效容值 < 标称 50% | ✋ 人工 | 需要所选 MLCC 的直流偏压曲线；0603 X5R/X7R 在 3.3–4.2 V 下值得核 |

| ES-002 TVS 地过孔 | 3 mm 内 <2 个地缝合孔（无则高危） | ✅ 自动 | U5/U6 的 GND 焊盘 3 mm 内 **0 个**地过孔。同一处缺陷被三条独立规则指向：`ES-002`（本行）、`RP-001`（USB 对换层孔 4.27–6.83 mm）、`BE-003`（J1 10 mm 内仅 1 个）。**能否判定取决于该焊盘是靠铺铜还是靠细线接地——覆铜几何不在快照里，所以当前只能按厂商指引补缝合孔，无法测量修好了多少** |
| IO-001 连接器无滤波/保护 | 25 mm 内无铁氧体/共模扼流圈/ESD 器件 | ✅ 自动 | 实测 J1（USB-C）最近的保护器件是 U5（USB ESD 阵列），**4.97 mm**，通过。本板无铁氧体与共模扼流圈，因此这条确认的是保护覆盖而非滤波覆盖 |
| IO-002 连接器地引脚比 | 地引脚 < max(2, 信号引脚/4) | ✋ 人工 | J1 是 USB-C，地引脚充足；需按实际连接的引脚数核 |
| SH-001 连接器开口槽谐振 | 槽谐振落在辐射源 ±20% | — | 本板无金属屏蔽壳，不构成谐振腔 |

## 已知的上游不一致

- 上游 README 与 `emc-precompliance.md` 声称 **44 条规则 / 18 类**；`pcb-emc-rules.md` 实际只写了 **42 条 `###` 条目 / 17 个分类**，且 `ML-001` 有实现无条目。
- 结论：**规则清单以 `emc_rules.py` 的实现 + `pcb-emc-rules.md` 的阈值为准，README 的计数不可当权威**。引用上游时同时标出规则 ID 与文件名。
