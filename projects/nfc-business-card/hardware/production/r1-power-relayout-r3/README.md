# R3 独立重排试验：不可下单

## 当前确定方案

本目录是从 R2 复制出的**独立嘉立创 EDA 工程**的一次布局和布线诊断，不是制造候选。编辑源为 [Power-Relayout-R3.eprj2](../../../../../eda/NFC-Card-R1-Power-Relayout-R3.eprj2)。R2 工程与制造文件保持原状。

R3 把显示供电的 15 个器件重新放到右上方，USB 附近的 R2（CC2 下拉）移到左侧，使器件功能区更容易辨认；J1、U5/U6 保护、U1 去耦、屏幕、板框和 NFC 线圈未移动。**电池电压采样仍保留**：它没有占用这次小孔放大后出现的主要冲突区，暂不需要删减。新布局的正反面铜箔见[预览图](../../records/r1-power-relayout-r3-preview.png)。

## 检查结果与阻塞

从保存重开的原生工程导出同一版快照、Gerber、BOM 和 CPL。下列结果是**修改过孔规则前**的图纸/导出数据检查，不代表实物或供应商接受。2026-09-24 已把当前 R3 工程的过孔规则改为内径最小/默认 0.30 mm、外径最小 0.50 mm/默认 0.55 mm；新规则下原生 DRC 报 **54 条过孔尺寸错误**，对应旧布线留下的小过孔，见[规则检查记录](../../records/r1-power-relayout-r3-via-rule-2026-09-24.json)。下表的其他检查与制造导出未在新规则下重跑，不能视为通过当前投产门禁。

| 项目 | R3 结果 |
| --- | --- |
| 原生 DRC、原理图与 PCB 引脚 | 旧规则下 0 项；当前规则下 54 条过孔尺寸错误。旧版检查中 66/66 位号与逐引脚网络一致 |
| 独立铜箔连通、屏幕/NFC 净空 | 通过；无断网、悬空铜岛或无用换层孔 |
| 不同网络铜间距低于 0.15 mm | 0 对，仅检查走线、焊盘和过孔；不含阻焊与供应商专有规则 |
| 板框和 USB 镀铜槽 | 本地几何通过，4 个槽保留 |
| 钻孔与孔环 | 142 个过孔中 **54 个约 0.25 mm**；最小径向孔环约 0.101 mm |
| 电气敏感布局 | C10–L1–Q1 **器件中心**三角面积从 R2 约 4.9 增至 R3 约 15.1 mm²；只是布局代理值，实际充放电回路与波形未验证 |

更直接的[命名焊盘距离复核](../../records/r1-power-relayout-r3-placement-review.json)也提示这次排布需要撤回局部位置：L1-1 ↔ C10-1 从 3.04 增至 7.37 mm，L1-2 ↔ Q1-3 从 1.37 增至 4.12 mm，C11-1 ↔ L1-2 从 4.40 增至 10.29 mm。这些是图纸焊盘中心距离，不等于实测回路性能，但足以说明不能因为排得整齐就接受 R3 的供电布局。

**阻塞：**自动布线生成的 54 个小孔违背本项目优先使用 0.30 mm 普通钻孔的目标。离线试把这 54 个孔改成 0.30 mm 钻孔／0.51 mm 外径后，<0.15 mm 的异网铜间距变成 **29 对**，最小约 **0.1166 mm**，主要集中在显示供电和 GND 扇出；仅改孔径不可投产。详见[验证总表](../../records/r1-power-relayout-r3-validation.json)与[放大孔试验](../../records/r1-power-relayout-r3-via-enlargement-trial.json)。本版**没有上传供应商 DFM**，也没有下单。

## 下一轮布局顺序

1. 以本工程的功能分区为起点，先缩短 C10–L1–Q1 的相对摆位和实际充放电回路；按器件数据手册复核 U4、Q1、二极管与电容的相对位置。不得仅为了排齐而扩大敏感回路。
2. 当前工程已把过孔内径最小/默认锁定在 **0.30 mm**，外径最小 0.50 mm、默认 0.55 mm（默认径向孔环 0.125 mm）。嘉立创 EDA 的新建 PCB 默认配置也已设为同尺寸的双面板规则。先解决现有 54 个违规过孔，再以至少约 0.10 mm 径向孔环、目标 0.15 mm 异网铜间距落线。优先在屏幕 FPC 扇出、显示供电与 GND 交汇处移孔、改线；USB 保护器件和主控去耦仍就近保留。必要时移动非敏感器件，不挤占屏幕和 NFC 净空。
3. 对新工程保存重开，重跑原生 DRC、独立连通性、净空、孔环/钻孔、板框、BOM/CPL；本地门禁过后才上传 Gerber/BOM/CPL 做供应商 PCB/SMT DFM。供应商的孔环、镀铜槽、阻焊桥、J1/U1 贴装危险仍需逐项关闭或取得书面确认。
4. 只有证明确实被电池采样器件或线路阻塞，才考虑按用户允许删除采样功能；删除需同步原理图、BOM、固件计划和重新验证。

本目录的 `*-gerber.zip`、`*-bom.csv`、`*-cpl.csv` 是**诊断导出**，用于核对实际小孔与布局数据，**不能作为订单文件**。复现：

```bash
python3 projects/nfc-business-card/scripts/check-r1-relayout-r3.py
```
