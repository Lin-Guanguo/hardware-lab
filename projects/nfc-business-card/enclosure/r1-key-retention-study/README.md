# 按钮防脱挡边：供打印询价的模型

## 当前确定方案

保持主体内腔 **3.2 mm**、整机 **4.8 mm**，单独调整键帽。用户接受打印后做少量打磨配合，先提供实体模型向供应商确认工艺。本目录为独立询价候选，不覆盖上一版模型。

挡边是围着按钮柱的防脱凸缘，**0.4 mm 指上下方向厚度，不是整颗键帽厚度，也不是向外伸出的宽度**。它不需要弹性扣入，从壳内安装后由孔边挡住。

本轮把外圈可用区域加厚至 **0.8 mm**，底面挖一个 5.6×5.6×0.4 mm 凹位，留下中央压柱，给开关让位。凹位跨在开关上方的部分仍有 **0.4 mm 局部厚度**；加厚区沿四个方向形成短弧，轴线处径向宽约 **0.6 mm**。这改善了部分边缘的几何截面，但没有做强度试验，不能宣称已经满足某种树脂的制造要求。

| 项目 | 尺寸 |
| --- | --- |
| 外露圆头 | Ø4 mm，顶边 R0.2 mm |
| 挡边外径 | Ø6.8 mm |
| 外壳导向孔 | Ø5.2 mm；圆头单边名义间隙 0.6 mm |
| 防脱径向搭接 | (6.8−5.2)/2 = 0.8 mm |
| 挡边外缘上下高度 | 0.8 mm；局部径向宽约 0.6 mm |
| 底面凹位 | 5.6×5.6 mm，深 0.4 mm |
| 中央压柱 | Ø2.6 mm |
| 整颗键帽包络 | 6.8×6.8×1.62 mm |
| 静止压头间隙 | 约 0.05 mm，实物需配合 |
| 完整检查位移 | 约 0.50 mm（含接触间隙及 0.45 mm 行程上界） |
| 完整行程竖向余量 | 约 0.08 mm，未扣除公差 |

> 这是三个独立小按钮，每颗约 6.8×6.8×1.62 mm，按 STEP 的 mm 单位加工。外缘上下厚 0.8 mm，底面局部顶层仍为 0.4 mm，外缘短弧径向宽约 0.6 mm。配套上壳仅供理解配合。请确认这类小件、薄顶层和短弧能否成型及完整去支撑；是否需要连件框；可选什么材料。按钮外圆、底面和中央压柱是配合面，请说明这些位置的支撑/打磨/涂层安排及能保证的尺寸偏差。用户可自行少量打磨，不要求整套一次装上即免修配。另附平挡边对照件，可比较哪种结构更容易制作。

## 打磨与装配

- 打磨可以处理**外圆偏大、局部毛刺、压柱偏长**，先定位实际接触处，取下按钮再修配和清理粉尘。
- 当前圆头对孔的单边名义间隙已有 0.6 mm，不应预先把圆头磨小或扩大孔，以免晃动增加。
- 不把防脱外缘、0.4 mm 局部顶层当作主要打磨面，也不要把挡边磨到能从孔里掉出。
- 压柱逐步修配，装好后必须松手回弹、静止不触发、中心及偏心按压不卡。打磨不能补回偏短压柱、偏小外径或损失的强度。
- 目前没有承诺工厂公差下必定可装；最终配合以实物为准。材料、胶层和 PCB 安装高度仍沿用上一版待验证项。

## 验证与复现

[几何报告](report.json)记录三颗键帽均为有效单实体，静止与完整开关无体积干涉；完整运动扫掠对上壳、底盖、PCB、固定开关体、屏幕及其余元件无干涉。另用覆盖所有旋转角度的环形扫掠包络验证新增外缘，名义几何通过，不仅检查某一安装朝向。USB 采用包围盒绕开源库无效 BREP。

STEP 重读、STL 封闭、FCStd 保存重开通过，源文件哈希未变。没有改变电路或上壳；没有验证树脂强度、回弹寿命、实际活动压头分界和完整公差链。基于当前库模型的旋转通过也不替代真实开关外形核对。
