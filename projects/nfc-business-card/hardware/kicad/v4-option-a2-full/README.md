# NFC V4 A2 完整范围合并失败候选

## 当前确定方案

666 段／88 孔，ERC 0、parity 0、DRC 59、16 未连接。full 仅表示整板连接范围的尝试，不是整板完成。C3 与其它地分量在合并后再次失联；BUSY、CS、USB D−、两 CC 及 TS 未接完，当前状态已保存重开核对并停止继续批量试路。

**仅为设计诊断，禁止作为制造包。**原生入口：[项目](NFC-Card-V4.kicad_pro)、[PCB](NFC-Card-V4.kicad_pcb)、[原理图](NFC-Card-V4.kicad_sch)。相对项目库齐全，BOM／网络、双层 0.8 mm、接口／天线基准及电池采样功能保留。

最新同版结论、顶底层图、前后路径、地岛根因、失败证据、电气／制造待办和复核命令见 [A2 报告](../../v4-option-a2-review.md)。旧 A 局部板／失败板及 D、phase1/2/3 保留。不同候选中通过的局部不能拼成整板通过。
