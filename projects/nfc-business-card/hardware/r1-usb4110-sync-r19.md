# R19：USB4110 原理图与 PCB 同步

## 当前确定方案

[R19 独立原生工程](../../../eda/NFC-Card-R1-Layout-Reset-R19-USB4110-Sync.eprj2)在 [R18B 接口诊断](production/r1-layout-reset-r18b/README.md)上替换原理图 J1 的整颗库器件。原理图现在使用嘉立创库中的 GCT USB4110-GF-A 符号、器件和封装；四个外壳脚编号 8–11、名称 `SHELL`，均接 GND。保存、关闭并重开后，PCB 原生 DRC **0 条**，不再有 `Import Changes`。这是同步修复，**未重布 PCB，也不可下单**。

R18B 原理图只把旧 USB4500 符号的物料属性和脚号改成 USB4110；EDA 重开时报 J1 的“器件属性有误／封装属性有误”。R19 删除该旧符号，放置完整官方 USB4110 符号，按原网络重新接 14 个有网络的引脚，SBU1/SBU2 保持不接。EDA“导入变更”窗口只列 J1 属性更新；应用后同步提示消失。

## 核对结果

- [检查记录](records/r1-layout-reset-r19-validation.json)：原理图与 PCB 均为 66 个位号、256 个引脚，独立逐引脚网络对账 0 差异；R19 相对 R18B 的全部位号／引脚网络 0 变化。
- R19 与 R18B 的 PCB 快照在器件、266 个焊盘、944 段走线、167 个过孔、板框、阻焊、丝印及实际铺铜上逐项相同。R18B 的[嘉立创 PCB／SMT DFM](production/r1-layout-reset-r18b/vendor-dfm-2026-09-26.md)可作为板图和摆位对照；R19 自身尚未重新上传。
- 原生工程数据库 `pragma quick_check` 为 `ok`。原生 DRC 0 与独立网表对账在保存、关闭、重开后重新执行。

## 后续门槛

1. 在下一独立候选中按 USB4110 官方焊盘位置整理 J1 到 ESD、CC、VBUS 的局部走线；先保持保护器件和关键去耦的电气关系，再比较过孔、长度和成品间距。
2. 定位嘉立创网页剩余的孔环、阻焊桥和局部铜间距危险；若属于标准封装固有几何，核对原厂图与板厂规则，不为消除计数任意改焊盘。
3. 真实 USB4110 外壳模型与新开口尚未验证。现有 5.8 mm 外壳名义干涉约 0.18 mm，需独立机械候选。
