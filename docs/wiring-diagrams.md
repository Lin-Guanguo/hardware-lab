# 接线图制作与归档方法

2026-09-19，用户确认偏好当前“实物主板外形 + 完整排针丝印 + 数字序号 + 可选择高亮”的 HTML 图。此格式作为本仓库后续接线图的默认形式，适用于所有项目。

## 统一目录

生成第一张接线图时，按下列结构创建目录；没有接线图的项目暂不创建目录或占位 README。

```text
projects/<项目名>/wiring-diagrams/
├── README.md                     # 图册、接线依据与验证状态
├── <接线主题>.html               # 可用浏览器直接打开的完整页面
└── sources/
    └── <接线主题>.html           # 可编辑、可嵌入对话的 HTML 片段
```

当前示例见 [Image Oracle 图册](../projects/image-oracle/wiring-diagrams/README.md)。其他项目产生接线图时沿用同名目录；未确认的硬件不预先画成确定接线图。

HTML 接线图是刻意保存的项目文档，源文件和独立页面一起纳入版本管理。不要保存临时预览副本，也不要只引用对话缓存路径。接线表和验证记录仍放在项目 `hardware/`、`docs/`，由图册链接过去。

## 默认画法

1. **按实物定位。** 根据已核对的照片和资料画出主板轮廓、天线、金属罩、USB 口、按钮等定位特征；标明元件正面／背面和摆放方向。当前 ESP32-S3-CAM 示例固定为“金属盖朝前、天线上、USB 下”。这不是其他板卡的通用布局。
2. **保留完整排针。** 左右两排按实物次序显示全部丝印，让用户可以数到目标针。GPIO 编号按原样保留，不能按数值重新排序。
3. **模块端决定圈号。** 顶部显示模块全部排针，并按实际顺序标 ①②③……；主板对应接线处显示同一圈号和模块信号名。圈号是模块针序，旁边的 `14`、`40` 等是主板 GPIO。只使用部分功能时保留原编号，例如按键 MID 仍是 ⑥，不重新编号为 ②。
4. **清楚表现本次接线。** 用高亮圆点、短连线和标签标出端点；未接脚保持中性样式并注明暂不接。灰色主板针脚只表示本图未高亮，不意味着未被摄像头、存储器或其他模块占用。
5. **单独说明分支。** 共地可另画面包板局部图，标明孔号、内部相通范围和公／母接头；不要让多条连接看起来需要挤进一个插孔。电源、电压、共地与信号线须区分。
6. **支持逐根定位。** 适合时增加“全部／某根线”的下拉选择，同步高亮模块端与主板端、更新简短连接说明。保留键盘可用的原生控件；不用无关动画或装饰面板。
7. **适应屏幕宽度。** 使用主题颜色、可读文字和实际容器宽度生成 SVG，窄屏调整排布，不能靠缩小整张图导致字看不清。中文用于说明，代码和代码注释用英文。

视觉布局可以复用，引脚事实必须逐项确认。未经确认的引脚不补猜；绘图不会自动更改固件，也不代表实物已接好或已通过测试。

## 制作与修改

先读目标项目 README、接线表、当前固件引脚常量及可用的实物照片。复用最接近的 `sources/` 图作为起点；换板卡时重新建立排针数据。

现有主板图用 HTML + 内联 SVG + 少量 JavaScript，无需图像生成模型：

- `left`、`right` 数组保存实物的左右排针顺序。
- `connections` 保存 `signal`、`pin`、`side`、从零起算的 `position` 和 `badge`；同一份数据驱动高亮及连接说明。
- `ResizeObserver` 在容器尺寸变化时重画，文字大小保持可读。
- `window.openai.widgetState`／`setWidgetState` 保存选中项；独立页面的导出壳提供兼容支持，不需要对话继续运行。

源文件是 HTML 片段；独立页面包含主题样式和运行所需的导出壳。修改源文件后重新导出，不直接编辑生成的独立页面，以免两份图不一致。新图需同步加入该项目图册；接线改变时，也要同步核对固件和接线文档。

## 导出与打开

本批图使用已安装的 Codex `visualize` 1.0.38 技能附带 `scripts/render.py` 导出。此工具用于给片段补齐独立页面，不参与硬件编译或烧录；升级技能后按当前安装位置调整工具路径。

以下从仓库根目录执行，以屏幕图为例。`--force` 会更新同名独立页面，输入和输出必须是不同文件：

```sh
visualize_renderer="$HOME/.codex/plugins/cache/openai-bundled/visualize/1.0.38/skills/visualize/scripts/render.py"
wiring_directory="$PWD/projects/image-oracle/wiring-diagrams"

python3 "$visualize_renderer" \
  "$wiring_directory/sources/display-pin-locations.html" \
  "$wiring_directory/display-pin-locations.html" \
  --title '屏幕接线位置 · ESP32-S3-CAM' --force

open "$wiring_directory/display-pin-locations.html"
```

其他图替换输入／输出文件名和标题；其他项目替换项目目录。现有独立页面可以直接打开，重导出时才需要上述工具。导出壳可能引用 CDN 图标／提示库，不将离线兼容性视为已验证能力。

工具如提示存在 `window.openai` 引用，检查是否只有受支持的 `widgetState`／`setWidgetState`；不要把依赖对话宿主的其他动作直接带入独立页面。本批三个交互图只有这两种 API。

## 检查与记录

- 逐项对照实物排针、接线表和固件映射，特别检查视角是否镜像、编号是否错位、电源与相邻 GPIO 是否混淆。
- 检查下拉选择、高亮、连接说明和恢复选中项，在 320 px 与桌面宽度下验证布局；可用浏览器时检查实际渲染。脚本模拟或语法检查不替代目视检查。
- 确认独立页面包含最新源片段，脚本可以解析，图册相对链接可用；归档原图时确认副本与原图一致。
- 执行 `git diff --check`；只修改图与文档不需要编译或烧录固件。
- 图册分别记录“接线方案”“源码已构建”“已烧录”“用户确认显示／按键实测”等状态，避免把图已生成写成硬件已验证。
