# E11 USB 数据扇出对照

E11 从 E9 独立复制，保持板框、器件位置和按键不变，只试验 J1 的 A6/B6、A7/B7 到 U5 的双层扇出。两轮受控方案分别使用 18 或 21 段线、10 个 12/24 mil 过孔，并把 DP/DM 分到错开的底层走线廊道。

结果没有形成可接受的 USB 数据连接：`USB_DP_CONN` 和 `USB_DM_CONN` 仍各有连接错误，且出现数据线与过孔、CC1、彼此之间以及 U5/C1 入口的间距冲突。试验铜线已删除，E11 保存重开后回到 56 个元件、242 个焊盘、0 段线、0 个过孔，DRC 恢复 E9 的 224 条基线。

这次对照排除了“只靠错开普通通孔就能在当前两层布局完成 USB 扇出”的路径。下一步应在不增加成品长宽和目标厚度的约束下，比较更换带内部过渡的 USB 封装、把 ESD 放到连接器另一面，或按嘉立创可制造叠层评估盲/埋孔与四层方案；不能继续堆叠长绕线。

验证记录：[E11 最终重开](records/e11-final-reopen.json)、[第二轮试线](records/e11-staggered-v2.json)。
