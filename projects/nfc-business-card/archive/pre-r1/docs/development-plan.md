# 开发顺序与验收

推荐顺序：先筛选能平铺的成品小板并确认 NFC 与固件行为，再验证透明壳、飞线装配与 RF。保留 ≤5 mm 目标，但不将桌面功能验证等同于已满足装壳尺寸。只有成品小板无法满足需求时再进入定制 PCB 流程。

## 装配方式与交付流程

用户希望避免增加 PCB 设计复杂度，当前优先使用现成小板 + 飞线 + 打印壳定位。具体组合见 [成品小板装配路线](../../../docs/usb-and-prototyping.md#当前优先成品小板--飞线--打印定位壳)。下面定制步骤仅在现成板方案不能满足尺寸或可靠性时启用。

| 顺序 | 具体工作 | 获得的结果 |
| --- | --- | --- |
| 1 | 核对 XIAO 类小板和屏幕驱动板的尺寸、版本、NFC 引脚与 USB 下载方式，讨论软件后准备功能样机 | 能在桌面验证、值得尝试平铺装壳的组合 |
| 2 | 编写并测试 USB 更新、按键切换、墨水屏显示与 NFC 链接的一致性 | 可工作的功能原型；原型板厚度不作为成品厚度 |
| 3 | 并行测试透明 SLA 薄壁样片，获取最终器件尺寸；安排屏幕、电池、PCB 和接口的位置 | 经测量的厚度预算和机械布局 |
| 4 | 先用打印壳定位、飞线连接并试装；若装配满足目标，直接进入整机测试。若不满足再联动设计定制 PCB 与外壳 | 飞线装配方案；必要时才生成 PCB 制造资料 |
| 5 | 审阅外壳资料后讨论打印；仅定制路线需要另行讨论制板与 PCBA | 打印外壳；定制路线额外获得已焊元件的电路板 |
| 6 | 首次烧录/调试、连接屏幕和电池、装壳与整机测试，必要时改板改壳 | 验证过的薄型样机，后续日常通过 USB 更新 |

PCB 是电路板，PCBA 是按设计把元件焊接到板上。飞线方案复用成品板上的屏幕驱动外围、充电/稳压和 USB 电路；若改为裸器件定制路线，这些电路才需要重新画入设计，不能省略。

设计和固件可在本项目中准备，工厂负责制板/小元件贴装与打印，用户主要负责实物检查、后装和测试；电池连接器或焊线方式在厚度设计时确定，暂不承诺完全免焊。工厂首烧需另行约定，日常 USB 升级需要预置 bootloader，保留 SWD 恢复焊盘。

## 阶段 0：本轮已完成

- 记录用户确认：没电可以停止 NFC、内容先写入固件。
- 官方资料对照，收敛 A/B/C 架构和外壳选项。
- 本机工具盘点、提出待讨论的安装范围。
- 下载 6 份数据手册，记录来源与 SHA-256；渲染核对关键机械图。
- 给出厚度预算、敏感性功耗模型和后续测试矩阵。

未完成也不冒充完成的内容：元件现货确认、正式 BOM、原理图、PCB、可加工 CAD、固件构建、实物测试。PDF 解析器对少数厂商文件发出结构警告；已保留原件并目视核对本轮使用的机械图，未因此修改 PDF。

## 阶段 1：桌面功能验证

当前先筛选 **XIAO nRF52840 / Plus + 成品屏幕驱动板**，让同一套部件有机会直接装壳；**EN04 集成板**或 **nRF52840 DK / PCA10056** 是桌面调试备选。nRF52832 DK 不再作为完整功能验证平台。先核对当前板卡版本、NFC 天线/引脚与 bootloader；DK 的板载调试 USB 与目标 MCU USB 要区别使用。详见 [USB 与原型路线](../../../docs/usb-and-prototyping.md)。

最小验证组合：开发板 + 兼容 NFC 天线 + 1.54 英寸屏幕转接板 + 按键。先由 USB/受控实验电源供电，暂不把未核对的小电池接入通用充电板。

验收：

- 构建官方 NFC 样例，再生成 3 个不同的 HTTPS URI；手机可读到各自内容。
- 按键确认后显示与 NFC 一致；屏幕刷新和 NFC 不互相破坏。
- 证明选中索引重启后恢复；全刷新超时能退出并重试。
- 获得 map 文件与电流测量，确认 nRF52840 的资源、升级分区与功耗。
- 验证 USB-C 正反插数据传输、反复上传后 NFC 正常，以及应用损坏后的按键恢复入口。

## 阶段 2：结构与天线样片

获取屏幕、按钮和至少一种薄电池样品；电池尚未确定保护、充电参数前只用于绝缘的机械包络检查。

制作等厚材料样片和独立 NFC 线圈测试板；比较右侧小线圈区与更大线圈方案。需要时使用借用/外包的 VNA、阻抗测量或制造商支持，不必第一步购买全部仪器。调谐参考 [Nordic NWP-026](https://docs.nordicsemi.com/r/bundle/nwp_026/page/wp/nwp_026/nwp_026_intro.html)，不能把文档的示例电感/电容直接当本板 BOM。

用户当前希望先尝试透明 SLA 打印；其提供的材料页标称最小壁厚 0.8 mm、精度 ±0.1 mm，先按 [试样安排](../../../enclosure/finish-and-manufacturing.md#当前透明-sla-试样安排) 验证后处理与大跨度平整度。成品卡套/薄片作为备选，采用时仍按 [量测表](../enclosure/card-holder-option.md) 核实尺寸。

验收：确认含电池、屏幕、手持和外壳时的读取位置/距离；记录线圈参数和调谐电容。完成打印试片、薄片粘接和按键手感检查。若薄电池的完整保护包太厚，在此阶段换型号或调整结构。

## 阶段 3：定制电路与外壳协同设计（条件分支）

仅当成品板飞线方案无法满足目标，且讨论后选择定制路线时进入本阶段；若现成板已满足装配要求，直接验证整机。

使用 KiCad 画原理图、定义所有电源状态，核对模块 NFC/USB/SWD/SPI/I²C 引脚占用。按真实屏幕参考电路完成升压外围；选定 FPC 与 USB-C 座并画最大高度包络。实现 Type-C 受电/数据连接与保护，加入 NFC 调谐焊盘、分段电流测点、SWD 和应用损坏时仍能使用的恢复按键。

板框先从已验证机械布局生成，电池使用缺口区域，模块等高件避开屏幕。导出 PCB STEP 到 FreeCAD 做干涉检查，再生成壳体。用真实尺寸包络代替仅供展示的漂亮模型。

验收：ERC/DRC 通过或每条例外都有解释；资料手册逐项核对 footprint；完整厚度分析通过；工厂确认 PCBA 和打印可制造性。生成可审阅的原理图 PDF、PCB 图、BOM、坐标文件与外壳 STEP/STL，再进入下单讨论。

## 阶段 4：首板与成品验证

先限流上电测电源，再授权烧录目标设备；首次烧录保留 SWD 恢复路径。充电器默认状态通过后才接电池，验证边用边充、低电量和充电后恢复。

| 验证项 | 最小可执行标准（工程目标） |
| --- | --- |
| NFC 兼容 | 至少 1 台 iPhone、1 台带 NFC 的 Android；若需桌面读卡器则加入明确型号/应用 |
| 正常读取 | 每种身份、每台设备，在标记位置近贴分别连续 20 次；记录成功率与耗时，不只截图一次 |
| 位置与距离 | 正反面、横竖方向、手持/桌面、裸板/装壳、装电池前后对照；给出实测可用区域 |
| 同时操作 | 手机持续贴近时按键，不输出半新半旧 NDEF；移开重贴后得到完整新身份 |
| 断电恢复 | 在选择保存、屏幕刷新、NDEF 发布等阶段断电；重启后恢复同一有效身份 |
| USB 编程 | 正反插可传数据；连续升级后 NFC 正常；断电/应用损坏可恢复，必要时可经 SWD 救援 |
| 低功耗 | 电池端记录待机、刷新、NFC 场保持、充电后恢复波形；按实测更新续航模型 |
| 电源 | 从低电量到满充、接拔 5 V、充电时刷新屏幕，无过压、重启循环或异常温升 |
| 厚度 | 卡尺测四角、中心、高器件与未按下键帽，最大值 ≤5.0 mm |
| 结构 | 正常按压无玻璃受力异常；胶/固定件可靠，轻度携带弯扭不压迫电池 |

这些是未来验收项，本轮没有实测通过项。读卡距离先以“标记位置近贴可靠”为 V1 目标，暂不宣传厘米数。

## 成本与时间的主要变量

不提供尚未询价的整机单价。成本分为一次性调试器/开发板、样品与适配板、PCB/贴片、外壳/夹具、后续改板五部分；第一台的成本通常主要由样品和加工起步费决定，而不是主控单价。

比较报价时分别询 0.8 mm 经济型 PCBA 与 0.6 mm 标准型/拼板，核对模块代购/寄料、元件最低数量、屏幕后装、电池运输和外壳后处理。预留至少一轮改板/改壳；在电池交期和 RF 样片结果之前不承诺交付日期。

## 待讨论的三个选择

1. 先核对成品小板组合并讨论对应固件工具；飞线方案无需先安装 KiCad。外壳建模工具另行讨论，定制路线才增加电路设计工具。
2. 外壳：已选择先试透明 SLA 材料，下一步核对具体材料、后处理与样片可制造性；全打印是否满足 ≤5 mm 留待验证。
3. 交互：三个独立按键优先，或愿意为五向键增加键帽和装配调试。

上述未决定事项不影响本轮研究完成，但会影响后续 CAD、采购与固件工作。用户已确认的掉电行为和固件更新方式无需重复询问。
