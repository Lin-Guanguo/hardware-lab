## 本轮局部重布与本地验证

- 薄孔环过孔放大后，在显示供电、USB 扇出、充电及控制信号区局部移孔、改线；移除一枚冗余 GND 过孔及其支线。未移动保护器件、去耦器件、U1、J1、板框或 NFC 天线。与上一电池采样候选相比，66 个器件及焊盘、丝印、铜皮区域均相同。
- 保存、关闭并重开原生工程后，原生 DRC **0**；原理图/PCB 位号 **66/66** 一致。独立铜连通、NFC 绕线与净空、板框和四个 USB 镀铜槽的本地检查通过。
- Gerber 有 **169 个过孔**，最小实际导出钻孔 **0.30226 mm**、最小径向孔环 **0.1016 mm**，没有低于 0.10 mm 的过孔；最小孔间净距约 **0.30396 mm**。
- [异网铜间距审计](../../records/r1-free-0p30-sense-ring-r2-clearance-audit.json)在走线、焊盘和过孔的对象对中未发现低于 **0.15 mm** 的间距。审计不含铺铜及阻焊开窗，圆角焊盘按近似形状计算，不能据此宣称供应商所有间距规则已通过。
- [复验脚本](../../../scripts/check-r1-ring-r2.py)对工程、快照、Gerber、BOM/CPL 及以上记录交叉校验；完整哈希见验证摘要。
