最新同版结论、顶底层图、前后路径、地岛根因、失败证据、电气／制造待办和复核命令见 [A2 报告](../../v4-option-a2-review.md)。旧 A 局部板／失败板及 D、phase1/2/3 保留。不同候选中通过的局部不能拼成整板通过。
