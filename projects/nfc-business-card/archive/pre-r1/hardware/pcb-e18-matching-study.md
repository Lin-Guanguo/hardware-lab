# E18 双侧调谐电容候选

后续面积复核发现右侧还能容纳更大的线圈，已另建 `Board1_5` / E19 五圈放大候选；E18 保留作对照，见 [线圈面积与工艺复核](nfc-coil-area-process-review.md)。

原始 [EDA 工程](../../../../../eda/archive/nfc-business-card/NFC-Business-Card-84x52-E14-Battery-Layout.eprj2) 中的 `Board1_4` 是从 E17 线圈图页复制的独立候选。E16 无线圈基线和 E17 无电容线圈研究仍保留。E18 在 NFC 线圈两端各加一只对地 C0G 电容焊位，完成了原理图、PCB 铜线、覆铜、制造数据与 V7 外壳的候选核对。**220 pF 只是首板测调起始值，不是实测确定的 RF 定值；当前不放行成品生产订单。**

## 电路和布局

- C23/C24：0603、C0G、220 pF、50 V、±5%，系统库器件 `GRM1885C1H221JA01D` / LCSC `C77032`。两只都在原理图 MCU 页，pin 1 接 `NFC1_TBD`、pin 2 接 GND。该网名由 E17 的原理图短接符合并；它是线圈直流连续性的表示，不能区分线圈两端。物理位置及连线才决定电容接在哪一侧。
- C23 中心 `(66.5,22.6)` mm，NFC 焊盘接外圈馈点 `(68.0,23.0)`；C24 中心 `(73.0,22.6)` mm，NFC 焊盘接内圈馈点 `(71.4,23.0)`。均位于天线无器件区 `y≥24` 之外。两条 0.25 mm NFC 支路分别以 12/8 mil 过孔换到底层；两只 GND 焊盘各有独立接地过孔。两层 GND 覆铜已重铺。
- 线路与过孔的精确候选坐标见 [E18 路线计划](e18-nfc-tuning-plan.json)。由于短接符合网，后续任何移动或重走 NFC 铜线都必须重跑 [物理分支检查](../scripts/check-e18-nfc-branches.py)；单靠 DRC 和逐引脚网表无法发现线圈旁路。

## 验证结果

| 检查 | E18 结果 |
| --- | --- |
| 保存后 PCB | 58 元件、248 焊盘、828 铜线、174 过孔、两层 GND 覆铜 |
| 落铜前净空 | 对 E17 快照运行 `check-proposed-route.py`：0 违规；与其它网络最窄铜边间隙 0.592 mm |
| 四页原理图 DRC | 各 0 项 |
| 原生 PCB DRC | 24 项均为 E16 已知 J1 槽边告警；新增项 0 |
| 原理图与 PCB 逐引脚 | 58 位号 / 238 引脚，0 网名差异 |
| 铜连通 | 47 网、0 断网、0 悬空端；`ground_reach` 仍是未校准的参考输出，不作门禁 |
| 线圈旁路 | 从数据副本断开外圈的一段铜线后，NFC 分成恰好两组：U1 pin 52 + NFC1 落点 + C23；U1 pin 54 + NFC2 落点 + C24 |
| 制造数据 | Gerber/钻孔/BOM/CPL/装配 PDF 均从 E18 重导；17 个 Gerber 成员、174 个过孔钻孔命中、BOM/CPL 各 58 位号、最大贴片位置差 0.0005 mm。**旧数量检查 `ok=true`，二次板框完整性检查改判失败：GKO 多一路径、GME 多一完整矩形**，见 [整板复核](pcb-e19-independent-review.md) |
| CAD | E18 STEP 的 C23/C24 实体分别在 `(65.7–67.3,22.2–23.0)` 和 `(72.2–73.8,22.2–23.0)` mm；板材及 V7 外壳检查均通过，0 实质外壳/肋位/键帽干涉 |

机器可读数据在 [E18 验证记录](records/e18-matching-validation-2026-09-23.json)。研究快照、制造导出及 STEP 在被 Git 忽略的 `artifacts/coil-api-study/`，可从 EDA 工程再生成；这些文件是候选验证产物，不是生产放行包。

## 尚需实物验证

1. 先用到货开发板和 PN532/手机验证 NFC 功能；这不能验证 E18 的板载线圈。要测实际线圈电感/电阻、装屏装电池入壳后的 13.56 MHz 谐振与读距，至少要制作一块 E18 射频样板，并据实测把 C23/C24 调成最终且对称的值。样板验证与成品批量放行是两个节点；仅靠手机读距不能反推谐振值。
2. 电池与屏幕到货后量完整包体、FPC/保护板/引线/胶带占用，并试装 V7 外壳；薄壁打印和按钮行程仍要实测。
3. RF 值、实物外形与装配方案固定后，才从同一保存版本重新导出并审核生产 Gerber、BOM/CPL、STEP 与板厂生产稿。
